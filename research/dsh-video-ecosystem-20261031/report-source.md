## A 结论：这一层已饱和，我们的位置在读完之后的回头路

**“让 Agent 能读视频”在 DSH 生态里已经是红海，靠这个说法没有位置。**
十天内外可见十个以上在维护的插件，全部围绕 B 站，分四层：纯转写、证据取用、工作台、自主选片。

我们视为核心的六项设计，已被至少三个独立仓库各自实现，其中两项连成本账都算好了：

| 我们的设计 | 已被实现于 | 重合程度 |
|---|---|---|
| 字幕优先、无字幕才转写 | 几乎全员 | 完全商品化 |
| 先文字后画面、按需取帧 | CZX2244/dsh-bilibili（两段式）、Sacredbluedragon/dsh-bili-watch（取用顺序） | 思路一致 |
| 抽帧拼版降低读图次数 | Aurum807/dsh-bilibili-video-summary（16 格拼版，190 次降到 12 次） | 一致，且带测算 |
| 帧图落盘可回查 | CZX2244/dsh-bilibili | 一致 |
| 失败出声、不静默降级 | Sacredbluedragon、CZX2244（降级带 note） | 部分重合 |
| 按 BV 号缓存复用 | zz12hui/dsh-bili-video-summary | 完全商品化 |

仍然没人做的四件：无损分页与续读游标、校对与区间审阅、处理完成与宿主读完与识别正确三态分离、跨宿主。

**判断：不加一份 DSH 原生插件。**若要让这波人用得上，用第三套薄适配复用现有核心，与已有 Codex、Claude Code 两套同类，不重写。

本轮是生态扫描，不是源码案例：只读 README 与市场页，未固定提交、未下载源码、未运行。下文所有功能描述都是对方自述，不构成实现事实。

## C 值得注意的三个实现细节

这三条不是借鉴对象，是提醒我们“别人也在同一处踩过”。

**成本自觉已经出现。** Aurum807 明写：一份 20 分钟视频逐张读图要 190 次以上，读 16 格拼图只要 12 次左右，全片结构先看完，具体参数再回读单帧核对。这与我们分镜预览的取舍同源，区别是他们把它写成了对外话术，我们写成了内部参数。

**“失败要出声”正在被独立发现。** Sacredbluedragon 明写抽帧类命令缺 ffmpeg 会直接报错、不会静默降级；CZX2244 写单个信息源失败不影响整体、各自降级为空并带 note。两者都比只写一句“可能识别有误”的做法硬。

**默认值设计比功能表更见功力。** CZX2244 的帧图落盘不自动清理，理由是便于模型随时 read_image；代价写明是磁盘占用。这是把“材料可回查”当默认而不是当选项，与我们的一致。

## D 尚无实现的四件

以下四条均为“在所读 README 与市场页中未见”，属于扫描结论，不是否定证明。

| 缺口 | 现状 | 我们的对应能力 |
|---|---|---|
| 无损分页与续读游标 | 全部是“一次交付一份内容”，长视频读完即占满上下文，没有 next_cursor | `delivery.next_cursor`、按页续读、局部区间精读 |
| 校对与区间审阅 | 一个都没有；遇到转写错误的统一回答是“如实标注可能不准”，然后结束 | `review prepare --start/--end`、校对稿导出、区间审阅与全片状态分离 |
| 三态分离 | 最好的是“单源失败带 note”，属于失败态，不是“读到什么程度” | 处理完成、宿主读完、识别正确分别报告，`remaining_ranges` |
| 跨宿主 | 九个全是 DSH 专用，无一份可搬 | Codex 与 Claude Code 两套薄插件共用核心 |

四件事的共同点：不产生漂亮 README，不出演示视频，只在“想核对某处画面”和“转写错了怎么办”时显形。这是本项目的实际护城河，也是它最不像产品的部分。

## E 对现有结论的改变

**方向不变，叙述要改。**对外不该说“让 Agent 读视频”，该说“读过的视频还能被追问、被校对、被复查”。前半句已经被十个人说完了。

**接入路径有了明确取舍。**DSH 插件是一行 npm 加一行 `dsh.profile.bundles`，我们是一整套 venv、FFmpeg、PowerShell 7 与薄插件安装。要让这波人用得上，成本最低的路径是补第三套薄适配复用共享核心，与 Codex、Claude Code 两套同规格，而不是重写一份原生插件。

**跨宿主主张在此刻稀缺。**上面九个全部绑死在 DSH，一个都搬不走。我们架构里唯一别人短期不会做的结构性差异就是这一点。

**风险项没有消失。**Hana 市场的 `内容摄取 (Bilibili Intake)` 已经在做回指校验、帧分析和知识地图，它把“证据”叙事吃进去了一半。我们的差异只剩全链一致性：材料、续读、校对、状态四件事必须同时成立才有意义。
