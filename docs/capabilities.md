# 当前能力与试用范围

更新：2026-11-04。Video Reader 按整包发布，包含 Reader、独立的通用任务模块 `reading_tasks` 和 Scroll Agent。模块分开维护职责，不按成熟度删掉其中一部分。DSH 薄包连接两套 MCP，队列与历史通过 Reader 的 `video_tasks` 提供，没有另造第三套阅读或任务核心。

## 已有真实使用与验证

| 能力 | 当前可做的事 | 证据与边界 |
|---|---|---|
| 通用视频阅读 | 读取 Bilibili、YouTube、本地视频；取得带时间的文字和原生图片，续读、精确取帧、导出 | 本机代表任务和源码安装验收通过。理解由宿主完成；字幕、ASR 和采样画面仍可能漏错。[发布验收](https://github.com/Kandecho/Video-Reader/blob/main/validation/release-20261104/report-source.md) |
| 通用队列与历史 | 管理待办、附言、来源、置顶/暂停/完成及结果；分流和批读复用 Reader | `reading_tasks` 独立于 Scroll Inbox；本机六条真实任务已处理并关联结果。人工完成与实际读完分别保留。[任务参考](tasks.md) |
| 独立 B 站账号 | 给组件单独扫码登录小号，使用该小号的首页推荐、访问权限和私信接口 | 组件保存自己的登录态，不要求共用浏览器或 DSH 的账号；Reader 与 Scroll 共用这个组件登录。这不是同时管理任意多个账号的承诺。[登录配置](installation.md) |
| 主号与组件小号私信 | 显式同步主号来信，保留原消息和附言，按启用界线将新视频入队；显式授权投递或汇报 | 真号收件已使用；10 月 23 日单次补发有用户收件确认，后续日推有平台接受记录。不是仅有模拟接口；平台接受和实际收件仍分别记录。[Inbox](inbox-queue.md)、[日试用证据](daily-trial.md) |
| 个人记录与状态 | 保存显式偏好、反馈、候选、日记录；查看中断、错误链和检查点，显式恢复已保存内容 | 不把未回复记为偏好；恢复不重新选片或自动补发。[Scroll 参考](scroll-reference.md) |

## 仍在试用或改进

| 部分 | 已达到的状态 | 仍需改进 |
|---|---|---|
| 每日定时工作流 | 有真实定时运行、评估和私信接口接受记录 | 出现过宿主路由超时、无检查点中断；长期连续成功及每次收件未全面验证。当前本机日试用与普通投递的授权范围不同 |
| 推荐与初步分流 | 能显式查看内容、识别类型、保存建议、待定及等待用户状态 | 推荐质量、材料不足与类型边界继续积累案例；分流建议不会自动执行 |
| 识别与核验 | 有本地 ASR、OCR、差异线索、复听和修订保全 | Qwen 强制中文退化仍保留问题记录；宿主语义校对与 Reader 取得材料是不同环节 |
| 宿主适配 | Codex / Claude 薄插件已有验证；DSH 当前提供整包薄适配 | DSH 的验证版本、入口和未测范围单列于 [DSH 指南](dsh.md)；不能把 CLI 实测泛化为所有 GUI、系统和模型 |

## 尚未接入

常驻私信监听、依据模型额度持续消费待办、自动完成整片理解，以及 Reader 自己运行独立语义初校模型，均未实施。当前新视频在显式同步来信时入队；后续读取由宿主按任务执行。安装 DSH 薄包不会自动启用日推、发送消息或新建调度。

当前机制与后续方向由[路线](https://github.com/Kandecho/Video-Reader/blob/main/planning/roadmap-20261021-source.md)维护；本页面向使用者说明能做什么。相关实现的差异见[相关项目](related-projects.md)。
