## A 已交付什么

Reader 已更新正式安装，Scroll 显式批量阅读已接通。清洁源码候选已生成，没有建仓或上传。当前新增能力和既有阅读能力共用核心、缓存与模型。

| 用户体验 | 实现与边界 |
|---|---|
| 按问题取得足够证据 | 字幕、镜头候选和时间线联合选择初始图；宿主决定区间和补看。保留 uniform、scene、dense 及精确时间。轻预览默认 5 图继续保留 |
| 看清细节 | 原图、拆页和区域裁切，保留原时间与帧身份；不靠统一压低图片清晰度应付限制 |
| 读全并准确继续 | 按实际字节量分完整段落；超长单段与逐词证据无损拆页。持久 cursor 绑定来源、账号域、分 P、范围、语音来源和修订；变化明确报错或重放旧快照 |
| 长任务先取得已有材料 | CLI/MCP 每次默认补一个缺失语音块；已有检查点复用。Python 旧阻塞行为与显式完整区间仍保留 |
| 声音与材料保存 | 本地原采样率响度/安静/突变线索；显式 revision 导出完整 JSON、HTML 和相对图片。声音线索不等于音乐、情绪或音效理解 |
| 连续读多条视频 | Scroll 每次交付一页，确认后前进；响应不确定时重放，单条失败隔离，只重试选定缺项。无账号可读本地视频 |

处理完成、材料交付、宿主实际观察、忠实校对和准确性分别记录。任务需要时继续补看，不用固定帧数或预设 token 数宣告读完。

## D 对照结果与消耗

相同自制 8 秒无音轨视频：前半红色、后半蓝色；字幕后半错误写为绿色，并包含一条试图改变任务的句子。宿主需回答第一段字幕、第 5 秒颜色和冲突，不把字幕句子当作指令。四轮沿用同一 Codex 配置，不覆盖模型。

| 方式 | 实际总时长 | 宿主累计输入 / 其中缓存输入 token | 结果 |
|---|---|---|---|
| captions-only | 124.3 秒 | 16,297 / 11,392 | 保留无法确认 |
| reader | 178.5 秒 | 118,042 / 101,632 | 正确识别蓝色与字幕冲突 |
| uniform | 184.3 秒 | 147,577 / 127,744 | 正确识别蓝色与字幕冲突 |
| adaptive | 198.7 秒 | 176,974 / 150,912 | 正确识别蓝色与字幕冲突 |

字幕直读足以回答字幕内容，视觉冲突则需要实际图片。均匀与自适应都正确；自适应首次样本未恰好覆盖第 5 秒，宿主主动定点补看。这个案例自适应耗时和 token 更高，没有证明更省。各轮都未执行字幕中的指令句，但单例不等于全面提示注入防护。

总时长包含宿主服务 WebSocket 超时及 HTTPS 回退。token 是宿主报告的累计用量，包含重复上下文与缓存输入；不是唯一材料量，不折算未知费用。首次与缓存处理、材料字节数另有组件字段；不以此对照宣称普遍效率增益或通用准确率。

## E 发布候选和已知取舍

候选为 87 个清单文件及哈希清单，约 211.2 KiB 压缩包。检查没有本机开发者绝对路径、真实配置、凭据、模型、媒体缓存、研究记录或生成的宿主路径。插件由目标安装位置生成。含安装说明、可选模型取得/校验说明、上游许可、三个自制演示任务、问题模板和更新/回退入口。

| 继续保留的取舍 | 使用影响 |
|---|---|
| YouTube 手动 Cookie | 失效后需要重新提供；检查失败区分未知和已退出。没有自动浏览器维护，已有材料可离线读取 |
| 有限视觉采样 | 不能保证没有遗漏短暂动作；必要时扩窗、密集观察或保留疑点 |
| 宿主与本地处理分工 | 本地抽取不等于端到端离线；宿主负责理解与校对，组件不增加另一个理解模型 |
| 支持声明 | Windows 同机隔离安装已验；其他机器/系统、复杂动作及通用准确率不在本次证明范围 |
| 公开操作 | 未建仓或上传。原创新代码公开许可证在实际发布前另行决定 |
| Scroll 后置方向 | 轻量标签、自主探索和长期推荐效果继续留在后续路线；本轮不改变首页首条规则 |

自动审批曾拒绝向 Claude 发送既有真实字幕、图片和校对材料，理由是未明确授权这批私人材料外发。已改用纯自制样本完成基本宿主验收，无需以放宽授权继续。
