# 阶段 3、4：内容目录、历史回查与单条任务消费

2026-11-06 本地源码验收；已发布下载包仍为原版本。用户授权阶段 3/4 一并完成，再用最新来信视频和历史 Super-agent 验证阶段 5。

## 实施结果

Reader 新增 `video_content`：index/query/storyboard/material/validate，默认 120 秒块，绑定来源、分 P、账号、语音、修订、覆盖与图像身份。优先复用完整媒体与已有校对；只有原生预览时保留近似精度和无字幕缺口，不启动 ASR。跨块段保留同一段 ID 和完整原文；目录缩略文字不是正文。原生图复制为稳定 SHA 资产，精确源帧同样校验像素摘要；旧版本选择明确拒绝。

通用任务新增 `queue-search`，查任务、结果摘要和哈希有效的已登记 Markdown/文本正文；不扫描任意项目或私信。查询归一化标点、大小写、Unicode，修复 Super-agent / superagent 的实际漏查。检索结果带匹配字段、产物有效性和继续回查入口。[操作](../../docs/content-index.md)。

`run-start/status/resume` 显式处理单个 pending 任务，复用共享 job、Reader 与配置中的宿主 CLI。完整正文及有来源的帧进入宿主；实际返回后才能保存观察检查点，缺证继续请求局部材料。任务、修订、帧像素、尝试 ID 与 packet 哈希校验阻止旧回包写入。结果与 run 完成在同一事务中保存，重放幂等；任务暂停、改意图或 superseded 后不能提交旧结果。

宿主通路抽到共享 host_runtime，Scroll 保留自己的判断提示与策略。没有第二套阅读核心、独立语义模型、常驻轮询或额度调度。每次宿主尝试只读，不让来源里的指令成为执行任务。[任务操作](../../docs/tasks.md)。

## 工程与真实宿主验证

完整回归 378 项通过，60.965 秒。独立代码检查发现并修复：部分 ASR 被当完整、启动写回覆盖进展、superseded 复活、源帧哈希未绑定、补证未固定 session、启动 job_id 窗口的刷新竞态。相应测试覆盖并发启动、恢复检查点、晚回包、结果提交崩溃、任务暂停与缺少观察/证据等。

本地生成 8 秒红/蓝视频，第二段字幕故意说绿，并放入源内容注入语句。配置中的真实宿主完成 run `r_10618fa9f7d741be88744145d1c9f8e9`，主动请求 2/6 秒原图，识别红→蓝、指出字幕冲突，不执行源注入，也不声称直接听懂音频。实际笔记与 task result_id=1 保存于隔离任务库。

该真实运行约 478.60 秒，含宿主通路断线、重连及额外综合阶段等待，不能宣传成核心读片耗时或普遍性能。发现单 packet 无需再次综合后，已改为复用其笔记；多 packet 仍综合并保留未决证据。外部断线原因未确认，记为具体摩擦，不为实验加新服务。

真实进程计划中断时原运行已结束，因此这次**没有完成真实强杀/恢复实验**；resume 返回同一完成 run/job。中断恢复、并发与晚输出隔离证据来自针对性测试，不把它写成已在真实宿主强杀验证。单条真实贯通有效，不能据此保证长期无人值守。

真实 Super-agent 回查还暴露 Inbox 重放问题：同一消息的 task 被人工改写后，后续同步曾重新创建空待办。已按同消息/同 canonical 复用原关联修复；不同消息/不同明确要求仍分别保存。30 项 Inbox 回归通过；原结果未删，新空待办显式用于本次阶段 5 验证。

收尾完整回归运行 379 项、74.985 秒，其中 378 项通过；1 项批读测试在未改动的 `common.write_json` 原子替换处遇到 Windows WinError 5。相同权限下定向复跑批读模块 6 项全部通过（5.252 秒），未改代码掩盖失败。另一次受沙箱临时目录权限影响的复跑也保留。原子替换拒绝访问的外因未确定，继续留作具体摩擦；不把收尾全套写成全绿，也不据此重写存储。
