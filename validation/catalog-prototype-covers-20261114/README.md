# 样稿封面与终止处置修订

用户接受新样稿后要求任务附视频封面，并明确原“待确认”条目已经完成，完成方式是终止。范围仍为独立样稿，不改变生产字段契约、状态和原目录。

cover-sources.json记录38个来源的封面调查：37个来源在既有平台view缓存中有data.pic，逐项核对BVID，17个另有下载信息交叉依据。现有preview_path是片中帧，不称为封面。调查没有发出新网络请求；缺失的是用户确认已下架的小米视频。

随后download-covers.py经授权，仅从37个明确的hdslb图片CDN地址下载原封面，3个工作线程且启动间隔2秒，不带登录凭据，不读取视频／评论，不修改生产缓存。原图验证后直接保存样稿assets，不进行改图或转码。download-result.json记录URL、缓存依据、尺寸、字节与SHA256；37成功、1无来源占位、0失败。浏览时全部为本地文件，同源任务复用。

样稿type-map.json中，小米记录增加展示状态done、完成方式“终止”，类型为“未注明”；原state=cancelled、原关闭记录及未读／未核查事实不变。筛选按任务展示状态，后续记录不参与改变父任务状态。

离线browser-check.cjs通过：40项已完成／2暂停，终止条目正确，41个任务封面来自37份本地原图，缺失占位及同源复用正确，原有答复、处置、历史和URL筛选保留。桌面明暗、390／320窄屏通过，人工查看实际渲染，模板静态扫描为[]。构建及浏览器前后受保护生产文件与数据库哈希不变。来源调查和下载明细按各自阶段计数，不将封面下载称为没有联网。
