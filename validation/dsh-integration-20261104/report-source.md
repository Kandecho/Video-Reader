# DSH 本机正式接入验证

日期：2026-11-04。接续 [Reader 端合约与官方源码考察](../../research/dsh-adaptation-20261104/report-source.md)。本批实际启动 DSH，向其模型发送公开视频链接和读取任务，并检查工具事件及 Reader 冻结交付。本机 Windows；核心仍为 0.10.0rc6，无新增阅读核心。

## 更新与接入

DSH 从 npm 全局安装的 **0.2.1-rc.5** 更新为官方 `next` 的 **0.2.2-rc.1**，安装后读取 package.json 确认版本。此次官方 `latest` 仍指向旧版，因此固定安装候选版，而非声称执行 latest 升级。原启动文件及两份 profile 配置已有组件内备份，保留回退至 0.2.1-rc.5 的命令。

使用独立 `vr-validation` profile，由官方 headless 模板创建；生产 web profile 的 patch 未修改。通过最后一层 patch 启用 DSH 自己的 credentials/authorization/deepseek-account，沿用本机已有凭据与模型路由。没有导出密钥或向其它应用读取账号。

Reader-only stdio 连接指向同一安装的 Python 和 launch_mcp.py，显式传 VIDEO_READER_CONFIG；未加载 Scroll、复制核心或另建模型服务。配置方式见 [DSH 手动接入](../../docs/dsh.md)。测试任务使用 read-only 权限预设和 never 审批策略；这描述本次宿主配置，不把外部 MCP 误称为操作系统读隔离。

## 三次实际任务

| 任务 | 观察到的行为 | 结果 |
|---|---|---|
| 公开 AIRI 视频 | 首次 open wait=0；查询同一 job，取 result；继续 read 页 | 8 次 Reader 工具调用，退出 0；生成带时间要点、区分视频宣称和未核实事实的中文简述 |
| 随机画面码与矛盾字幕 | 8 秒无音轨测试片；提示词、字幕、文件名不含两个随机码，真值在 DSH 工作区之外；只调用 Reader | 7 次工具调用，退出 0；两个五字符码均完全匹配，红/蓝背景正确；按 limit=1 和 continue 取得两条字幕，指出颜色矛盾 |
| 同一 DSH 会话接续 | 新进程传原 session-id；复用 Reader session，不重新 open；精确请求 2 秒、6 秒 | 4 次工具调用，退出 0；两个时间点与随机码再次正确，Reader 记录均为 requested_timestamp |

三次共 19 次工具调用，只使用 `mcp__video_reader__*`，覆盖 open/job/read/transcript/continue；没有 shell、文件工具或网页检索绕过 Reader。读取结果不是仅由 MCP 合约推断，模型实际答对了未预先告诉它的视觉码。两次颜色字幕均与画面不符，模型指出冲突；字幕中的越权句未改变这次回答。这只验证该样例，不推广为通用提示注入防护承诺。

AIRI 两页冻结交付包含全片 49 段候选字幕和 8+3 张原生图片，模型给出三个带时间的内容要点；没有读取评论、安装所介绍软件或发送平台消息。图像是采样，机器字幕也未逐句校对，因此这次回答不是对完整视频每帧、原声或项目功能的全面核实。

## 发现与恢复

- 初次视觉回答使用 overview/adaptive 画面描述任务时间。后续明确精确取帧，复用相同会话确认 00:02.000 和 00:06.000；采样包含某时刻不等于请求了精确时间。
- 监督提示把 timestamps 写成字符串，工具 schema 拒绝；模型改为字符串列表后成功。属于测试提示的参数错误，没有修改 Reader 兼容错误类型。
- headless 的 JSON 事件投影会截断长字符串，不能把投影尾部截断误判为模型未收到材料。本批另核对 Reader 冻结交付的字幕、图片和后续页。
- DSH headless 默认不使用 GUI 凭据；按照当前版本官方说明，验证 patch 显式恢复其原生凭据服务。这与默认 web profile 的行为不同。

原始任务、完整事件、回答、备份和账号配置均保留在本地私有区；公开 [summary.json](summary.json) 保存核查结果与事件/回答摘要值，不发布机器路径或凭据。

本批文档检查覆盖 13 个入口、202 个本地链接，无失效目标；源码分发回归 1 项通过，公开文件扫描无私有路径或凭据命中。分发检查曾受沙箱临时目录权限阻止，改在正常临时目录运行后通过；没有改测试或依赖来绕过检查。

## 可以据此说什么

已验证：本机 DSH 0.2.2-rc.1 的 CLI headless 可通过手动 Reader stdio 接入，取得真实视频材料与原生图像，处理普通 job、字幕接续、会话恢复及精确时间点读取。

未验证：DSH web/desktop 的 GUI 安装与交互、其它系统和模型路由、npm 薄 bundle、插件市场索引收录。没有据此扩张已发布源码包的跨机或全宿主验收范围。原 rc6 Release 资产保持不变。
