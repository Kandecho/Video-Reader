## 干净安装与代表任务

在另一盘中文和空格目录中，从空 uv 依赖缓存创建新 Python 3.12.13 环境，仅按候选包运行 bootstrap。没有复制现用配置、凭据、语音模型、视频缓存或研究环境。该方式是同机隔离验收，不冒充另一台机器实测。

默认 mcp / vision 安装成功，doctor 明确报告缺少 faster-whisper 包和语音模型，基础字幕读取仍可运行。随后按贡献说明增装 asr 包完成全套测试，仍未下载语音模型。Gemini 始终关闭。

公开合成片长 8 秒，前半红、后半蓝，没有音轨；两条中英文字幕的第二条故意写成绿色并含指令式句子。本次宿主查看精确 5 秒图像，确认为蓝色；字幕原句完整保留为材料，不遵从其中指令，也不声称听到声音。

- limit=1 的双语字幕分页、游标接续和同游标重放一致。
- 从目录外启动 CLI，新进程取得已有 job 结果，材料状态和时间可回查。
- 两套生成适配器分别初始化 Reader / Scroll 共四个真实 stdio 连接。Reader 20 工具、Scroll 7 工具，实际取得原生图像；本地队列查询不需平台登录。
- 导出明确选择 revision 0，保留未校对原文；导出目录复制到新位置后，所有相对图像引用均能解析，未引用原缓存作为图像资产。

这验证接入配置与协议，不宣称所有宿主模型都完成了语义理解或用户体验验收。Bilibili / YouTube、实际 ASR 与可选 GPU 的既有实测保留原日期和范围，本轮不重复登录、续期、私信或日推。
