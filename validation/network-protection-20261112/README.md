# 正常积压与异常请求保护

日期：2026-11-12。本地实现与离线验收；未联网取片、消费生产队列、恢复日推/后台收件或发布。

## 结果

默认 `preview.network.daily_requests=null`，每日计数保留。显式正整数日限额仍兼容；同账号继续共享锁与至少2秒请求间隔。旧120计数不阻断新默认策略，不清除既有平台暂停。

保护依赖实际行为：完整请求/响应摘要出现短时重复模式时，只冷却涉及的请求；连续瞬态故障达到阈值才暂时冷却账号。分页、来源、正文及HTTP Range进入指纹，WBI已识别动态签名被排除。404等来源错误不会变成账号服务故障。下载器首字节表示进展，完整读取才参与响应重复检测；流式读取不会计成多个请求。

临时退避返回原因和retry_at。Consumer保存waiting及检查点，后台到期复用原run/许可，不新增任务名额或宿主重试次数。媒体、原生字幕和下载器字幕均保留保护信息；普通字幕不可用仍按原流程回退。真实HTTP/平台限制继续持久暂停。

默认观察窗口120秒，瞬态故障阈值3，重复观察至少8次且周期至少3轮；冷却30秒起，重复触发延长至最多300秒。它们属于工程参数，未测试平台安全阈值。完整规则见[操作参考](../../docs/reader-reference.md#联网保护与临时退避2026-11-12)。

## 验证

- 新增网络保护35项：正常超过120次、两进程160次共享计数、成功重复/小循环、较大重复阈值、分页/Range区分、连续故障及404隔离、跨日期/迟到回包、真实暂停、缓存、下载字节反馈和子进程错误传播。
- 新增任务等待6项：原检查点、截止前不启动、到期原run恢复、原permit/计数保留、用户暂停及社区状态。
- 相关回归：后台与任务消费44项；既有网络相关14项；字幕材料7项；Agent 22项、社区19项、发现7项均通过。组合检查有复用，不按多次运行累加。
- 独立代码复核与针对字幕/过期deadline的离线fake验证无剩余阻塞。没有用生产请求验证平台的限流阈值。

跨进程检查首次曾出现历史Windows原子替换 `WinError 5`；该单项复验及随后整合通过。此问题未在本批修复，也不据复验通过宣称已消除。
