## A 日常怎么用

直接说：**“用 Video Reader 帮我挑两条视频。”**
可以再补主题、偏好，或对上次结果给反馈。
不需要你找链接、敲命令或每条生成笔记。

```flow LR
账号推荐或主题搜索 -> 共享材料: 缓存优先
共享材料 -> 轻预览: 字幕与原生图
轻预览 -> 宿主选片: 结合明确偏好与反馈
宿主选片 -> 本地留档: 理由、材料范围与缺项
本地留档 --> 主号私信: 仅在明确启用后
```

没有值得推荐的内容，可以只留档。
材料不足就保留缺项，不把标题当作看过。
完整讨论仍使用原有阅读、返读和校对流程。

## D 现在什么开着、什么没开

```kv
手动单轮: 可用，默认只留档
主号收件: 三轮实际确认
日常自动私信: 关闭
生产自动唤醒: 关闭
OS 定时任务: 未创建
常驻私信监听: 未启用
自动评论与收藏: 不做
新增模型或数据库服务: 没有
```

可选唤醒支持固定间隔、区间间隔和允许时段。
时区、数值和启用状态都来自配置，不硬编码。
保存配置不会创建后台任务。
上一轮没结束就不并发，错过窗口不积压补跑。

日常若启用私信，只发送简短合并推荐。
平台接受不冒充收件，失败和不确定结果不自动重试。
本次没有在三轮测试后追加消息。

## E 投入边界与下一步

**先少量日常试用，不再加重型系统。**
真实偏好与反馈还没积累，不能宣称推荐已很懂你。
下一步重点是选片是否有用，而不是训练推荐模型。

本次证明了流程，不代表已完成长期成本优化。
