## 实现

run-start 增加成对的 index_id/block_ids。宿主从现有目录、关键词候选与必要邻域选择块；消费者使用绑定的来源、语音轨、上下文、块长与修订，取得完整原段和现成图像。不会补转写未选尾部，空块要求先补材料。原生字幕 auto 继续复用 captions 快照。默认完整读取保持不变。

状态和结果区分本次计划与整个目录、未选部分、语音缺口，并给出返回全目录的 continuation。选块不是已观察或任务充分性证明。选块宿主必须明确报告 task_satisfied；不足时保存草稿、保留待办。换选择不能默默加入旧 run；中断恢复仍只续未接受包。

每次宿主尝试独立保存 metrics.json：packet/attempt、耗时、提示词字节、图像 ID/SHA/尺寸/字节及 CLI 实报 input/cached_input/output tokens。汇总包括失败、同包重复与旧尝试未测数。已知值可以是小计，未知为 null；返回与观察被接受分开。

模型请求数、模型上下文内的图像出现次数、实际首次可用答案时间仍未知。该批没有改变默认分包大小、参考全文策略或主聊天图片生命周期。
